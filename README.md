## Technical Stack & Standards

- **HTML5 & CSS3**
- **Tailwind CSS** (via CDN with customized color tokens and fonts)
- **Vanilla JavaScript** (Zero heavy dependencies, modular, performant)
- **Design Tokens & Fonts**:
  - Headings: `Outfit` (Google Fonts)
  - Body & Numbers: `Plus Jakarta Sans` (Google Fonts)
  - Colors: Urban Auto Gold (`#F59E0B`), Eco Emerald Green (`#10B981`), Night Slate (`#0B0F19`), Pure White (`#FFFFFF`)

## Global UX & Layout Standards

1. **Consistent Global Footer**:
   - 100% consistent across all 8 pages with the identical structure, logo icon, branding, navigation links, contact info, regulatory trust badges, and bright high-contrast text.
2. **Fixed / Sticky Header**:
   - Header remains fixed at the top while scrolling with a backdrop blur transition.
   - Desktop header stays strictly on **one line**: `Logo | Navigation | Dark Mode | RTL/LTR | Book a Ride CTA`.
   - `Book a Ride` CTA navigates directly to `booking.html`.
3. **Mobile Drawer Navigation**:
   - Clean mobile header with `Logo [spacer] Menu ☰`.
   - Dark Mode and RTL/LTR controls sit **inside the mobile drawer below navigation links**.
4. **Browser Tab Title & Favicon**:
   - Professional SVG favicon (`assets/images/icons/favicon.svg`) linked on every page.
   - Relevant, descriptive `<title>` on every page.
5. **Scroll-to-Top / Up Arrow Button**:
   - Appears after scrolling 300px on every page.
   - Smoothly scrolls to top in Light, Dark, LTR, and RTL modes.
6. **Strong Dark Mode Contrast**:
   - Background: `#000000` (pure black).
   - Primary Text: `#FFFFFF` (pure white).
   - High-contrast cards, borders, and controls throughout.
